# Organización de Gobernanza MCP

## Estructura

```
000-mcp-gobernanza/
├─ 007-mcp-token-resolution/
├─ 017-garantizar-mcp-activos/
```

## Propósito

Specs transversales de plataforma MCP que no corresponden a la integración de una herramienta específica, sino a la gobernanza, resolución de tokens, activación y ciclo de vida de los MCPs en el kit.

## Convención

- Origen: Kit Agents_IA_TECH interno
- Todas las specs deben incluir bloque **Origen** en cabecera para búsqueda rápida.
