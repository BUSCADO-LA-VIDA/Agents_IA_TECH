# Quickstart 015
Guía de uso

## Prerequisitos
- PowerShell 7+
- Git
- Repo accesible

## Pasos
1. Ejecutar sync-kit.ps1
   ```powershell
   .\scripts\sync-kit.ps1
   ```
2. Ejecutar bootstrap.ps1
   ```powershell
   .\scripts\bootstrap.ps1
   ```
3. Verificar módulos sincronizados

## Ejemplo de Salida Esperada
[INFO] Sync-kit descargado
[OK] Bootstrap ejecutado
[OK] Módulos sincronizados

## Troubleshooting
- Repo no accesible: Verificar conexión
- Módulos faltantes: Ejecutar sync-kit.ps1
