# Spec 027 - Patrón estructura de proyecto obligatorio

## Objetivo
Garantizar que todo proyecto tenga misma estructura de directorios y arquitectura canónica.

## Requisitos funcionales
FR-01: Definir estructura canónica Documentacion/<App>/ + src/<App>/ en .doc_agents/patterns/project-structure.md.
FR-02: Skill project-structure que valida estructura al inicio de speckit-specify.
FR-03: ADR-000x-standard-structure.md que fija estructura obligatoria.
FR-04: En speckit-plan añadir checklist de estructura y validación con graphify.
FR-05: Docker/Docker-compose estructura de directorios normalizada con regla de oro de secretos.

## Criterios de aceptación
* Patrón documentado sin placeholders.
* Skill valida estructura y falla si no cumple.
* ADR aprobada.
