# OpenWiki Documentation

This wiki provides documentation for the OpenCode agent system repository.

## Overview

This repository contains the OpenCode agent system, which includes various specialized agents (e.g., api-developer, arquitecto, devops, etc.), their specifications, skills, and associated documentation. The system is designed to assist with software development tasks through specialized AI agents.

## Getting Started

To get started with this repository:

1. Clone the repository
2. Review the [agent specifications](./.github/agents/) to understand each agent's role
3. Review the [skills](./.github/skills/) to understand available capabilities
4. Consult the [agent documentation](./Documentacion/agents/) for detailed specifications
5. Review the [agent configurations](./.opencode/agents/) for local agent definitions
